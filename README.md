# Линейная лаборатория

Локальное приложение для изучения и сравнения линейных регрессий. Интерфейс работает в браузере; реальные расчеты выполняют scikit-learn, skglm и CVXPY. Данные и сохраненные эксперименты остаются на вашем компьютере.

## Запуск

Нужен Python **3.11 или новее**. Распакуйте архив, откройте терминал в папке `linear-lab` и выполните:

```bash
python run.py
```

В Linux, если команда `python` отсутствует, используйте `python3 run.py`. Первый запуск создает `.venv` и устанавливает зафиксированные зависимости. Для этого нужен интернет; подготовка может занять несколько минут. После установки открывается [http://127.0.0.1:8765](http://127.0.0.1:8765). Следующие запуски используют готовое окружение. Остановка: `Ctrl+C` в терминале.

На Linux может потребоваться системный пакет `python3-venv`, если установленный Python не умеет создавать окружения. Установите его обычным способом для вашей ОС либо используйте уже подготовленное окружение:

```bash
python -m pip install -r requirements.txt
python run.py --system
```

Дополнительные параметры:

```bash
python run.py --no-browser --port 8766
```

Файл `.env` подхватывается при запуске. Чтобы изменить папку данных, скопируйте `.env.example` в `.env` и настройте `LINEAR_LAB_DATA`. По умолчанию данные находятся в `~/.linear-lab`. Интерфейс не требует Node.js и внешних CDN.

## Что можно делать

- **29 моделей:** МНК, Ridge, Lasso, ElasticNet, Lars, LassoLars, OMP, SGD, RANSAC, Theil–Sen, Huber, BayesianRidge, ARD, Quantile, Poisson, Gamma, Tweedie, LinearSVR, неотрицательный МНК, Weighted/Adaptive/Group/Sparse Group/Fused Lasso, Тихонов, L₀, SCAD, MCP и Square-root Lasso.
- **Данные:** динамический каталог загрузчиков и генераторов установленного sklearn, 9 управляемых синтетических сценариев, поддерживаемые табличные `make_*`, CSV/TSV/XLSX, OpenML. Можно выбрать числовую цель, признаки и отредактировать наблюдения. Редактирование сохраняет новую версию, включая строки вне открытой страницы.
- **12 интерактивных графиков:** 2D-срез, 3D-предсказание, история ошибки, коэффициенты, фактическое против предсказанного, путь регуляризации, геометрия/профиль штрафа, поверхность цели, остатки, корреляция, кривая размера обучающей выборки и перестановочная важность.
- **Метрики:** 15 стандартных регрессионных показателей и собственная числовая формула. Можно включить все. Для неподходящей области значений выводится причина. Направление сравнения можно выбрать самостоятельно.
- **Эксперименты:** единое разделение данных для моделей, подбор α по проверочной части, перекрестная проверка только на обучающей части, отдельное открытие итогового теста, сохранение настроек и результатов, экспорт JSON/CSV и обученного конвейера `joblib`.
- **Объяснения:** 20 уроков с запускаемыми примерами, словарь, пояснения моделей и параметров, точные математические формулы.

`Ctrl+Enter` запускает обучение, `Ctrl+S` открывает сохранение, пробел управляет воспроизведением шагов вне полей ввода. Тему можно переключать. Для длительного расчета есть отмена: завершается его отдельный процесс.

## Как читать историю

SGD записывает настоящие эпохи `partial_fit`; Lars и OMP публикуют путь коэффициентов. LassoLars показывает решения для изменяющегося α. RANSAC записывает кандидатов и итоговое решение. Для моделей, не публикующих промежуточные состояния, показан итог. Путь α является отдельным набором расчетов, а не эпохами одной модели. На поверхности варьируются два коэффициента, остальные параметры зафиксированы; диагностическая MSE подписывается отдельно от реальной цели оптимизации.

## Ограничения

Все загрузчики sklearn перечисляются в каталоге, но тексты, большие разреженные матрицы и часть наборов изображений требуют отдельных адаптеров и не запускаются как табличная регрессия. Классовые номера не выбираются числовой целью автоматически. Внешние загрузки требуют интернета и доступности источника.

Точный L₀-перебор ограничен 12 преобразованными признаками. SCAD/MCP используют библиотечные численные решатели и не гарантируют глобальный минимум. Первое обучение skglm может занять несколько минут из-за компиляции Numba. Кривые обучения, пути α и важность требуют дополнительных обучений. Графики используют ограниченное число точек; обучение использует весь допустимый набор.

Лаборатория запускается на локальном адресе без аккаунтов. Для публикации на сервере нужны отдельная настройка доступа и размещение Python-сервиса. Команда `--host` позволяет изменить адрес привязки, но сама по себе не создает полноценную публичную службу.

## Исходники и проверки

```text
linear_lab/
  app.py          HTTP API и сборка приложения
  datasets.py     адаптеры, генераторы, версии таблиц
  models.py       реестр и библиотечные модели
  training.py     подготовка, обучение и диагностика
  metrics.py      показатели и числовые формулы
  jobs.py         процессы расчетов и эксперименты
  teaching.py     уроки и словарь
web/
  app.js          состояние и действия интерфейса
  charts.js       интерактивные графики Plotly
  vendor/         локальные Plotly и KaTeX
tests/            численные, API и DOM-проверки
docs/             руководство, исследования и проверенные сценарии
```

Проверки Python:

```bash
python -m pip install -r requirements-dev.txt
python -m pytest -q tests
```

DOM-проверки при установленном Node.js 22.12 или новее:

```bash
npm ci
node --test tests/frontend.mjs
```

Node.js используется только для разработки и DOM-проверок интерфейса. Запуск лаборатории через `run.py` его не требует.
