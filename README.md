# Линейная лаборатория

Локальное приложение для изучения регрессии: загрузить таблицу, посмотреть связи на графиках, подготовить признаки, обучить модель и сравнить качество. Интерфейс работает в браузере, расчеты выполняют настоящие scikit-learn, skglm, CVXPY и Optuna. Данные и эксперименты сохраняются на вашем компьютере.

## Запуск

Нужен установленный **Python 3.11 или новее**. Распакуйте весь архив в обычную папку, затем откройте запускатель:

| Система | Файл |
|---|---|
| Windows | Двойной щелчок по `start.bat` |
| macOS | Двойной щелчок по `start.command` |
| Linux | `start.sh` → «Запустить в терминале», либо `./start.sh` |

Первый запуск создает отдельное окружение `.venv` и устанавливает библиотеки. Для установки нужен интернет; она может занять несколько минут. Затем открывается браузер. Обычно адрес — [http://127.0.0.1:8765](http://127.0.0.1:8765); занятый порт автоматически заменяется свободным. Повторный запуск использует подготовленное окружение. Для остановки нажмите `Ctrl+C` в окне запуска.

Если удобнее терминал, из папки проекта выполните:

```bash
python run.py
```

На Linux и macOS команда может называться `python3`. Node.js для работы лаборатории не нужен. Это приложение с Python, а не самостоятельный бинарный установщик. Выполнение запускателей проверялось на Linux; Windows и macOS требуют проверки на этих системах.

Проблемы запуска, диагностика и параметры команд описаны в [инструкции запуска](docs/launch.md).

## Первый опыт

1. Откройте **«Мои датасеты» → «Создать пример»**. Выберите **«Начать с понятной прямой»** и нажмите **«Создать и исследовать»**.
2. Посмотрите 2D и 3D исходных точек. Названия признаков выделены мятным, цель — коралловым. Меняйте оси и окраску, чтобы увидеть, что именно связано с ответом.
3. Нажмите **«Использовать для обучения»**. Выберите OLS, оставьте обычную подготовку данных и нажмите **«Обучить модель»**.
4. Выберите Ridge и сравните варианты **«Слабее»**, **«Исходный»**, **«Сильнее»**. Следите за коэффициентами и ошибкой на части **«Выбор»**.

Рядом с настройками есть `?`: наведите курсор, перейдите клавишей `Tab` или нажмите. Пояснение содержит пример, переход к уроку и источник. В разделе **«Разобраться»** — 32 урока и словарь из 92 понятий. Подробный маршрут: [руководство](docs/guide.md).

## Возможности

| Задача | Инструменты |
|---|---|
| Собрать данные | Свои CSV/TSV/Excel, OpenML, каталог sklearn, 9 учебных генераторов; библиотека с поиском, задачами, метками и характеристиками |
| Исследовать таблицу | 2D/3D до обучения, числовая и категориальная окраска, распределения, корреляции, пропуски, квантили и исходные строки |
| Подготовить признаки | 6 способов заполнения пропусков, 5 вариантов масштаба, 6 числовых преобразований, полиномы, взаимодействия, флаги пропусков, ограничение крайних значений, отбор признаков |
| Изменить состав обучения | Повторение редких строк, уменьшение обычной области, SMOTER и SMOGN для непрерывной цели; реальный просмотр до/после |
| Выбрать модель | 29 регрессоров: OLS, Ridge, Lasso, ElasticNet, Lars, OMP, SGD, Huber, RANSAC, Theil–Sen, байесовские, GLM и структурные/невыпуклые штрафы |
| Проверить качество | 15 стандартных метрик, собственная числовая формула, 9 схем перекрестной проверки, отдельное открытие итогового теста |
| Подобрать настройки | Сетка, случайный поиск, Optuna TPE/Random, последовательное сокращение сетки или случайных кандидатов; таблица и график реальных попыток |
| Разобрать результат | 12 интерактивных графиков: прогнозы, реальные шаги обучения, коэффициенты, остатки, путь штрафа, поверхность цели, важность и кривые объема данных |
| Сохранить результат | Эксперименты, CSV/JSON результата; модель Joblib, Pickle, Skops, ONNX, ZIP с кодом и паспортом; отдельный паспорт JSON |

Простые варианты параметров и режим **«Точные параметры»** используют одни и те же настройки модели. Одинаковое `alpha` у Ridge и Lasso не означает одинаковую силу штрафа: формы и нормировки функций различаются.

Обучение преобразований, отбор признаков и пересэмплирование используют только обучающую часть. В каждом разбиении перекрестной проверки эта подготовка выполняется заново. Поиск выбирает параметры внутри внешнего обучения; итоговый тест остается закрытым до явного открытия.

## Что учитывать

Каталог различает регрессию, классификацию, кластеризацию и временные ряды. Это классификация **данных**: обучающий раздел здесь посвящен регрессии и требует числовой цели. Тексты, большие разреженные матрицы и часть изображений представлены в каталоге с причиной отсутствия адаптера. Внешние загрузки требуют доступного источника и сети.

SMOTER/SMOGN создают синтетические строки только для исходных числовых признаков. Для категорий доступны повторение и удаление целых строк. Для временных рядов пересэмплирование выключено. Подготовленная таблица ограничена 2000 признаками и 15 млн ячеек; точный L₀ — 12 признаками. SCAD/MCP не гарантируют глобальный минимум.

ONNX доступен для совместимых полных конвейеров после проверки совпадения прогнозов через ONNX Runtime. Если модель или преобразование не поддерживаются, интерфейс показывает причину. Python-форматам нужны совместимые версии зависимостей и код `linear_lab`; ZIP включает их описание и исходники.

Несколько работников ускоряют дорогие независимые расчеты, но могут замедлить маленький Ridge. По умолчанию используется один, доступны 1–4. Измерения и использование готовых C/Cython/BLAS/Numba-вычислений — в [документе производительности](docs/performance.md).

SGD записывает настоящие эпохи; Lars/OMP — путь коэффициентов, RANSAC — кандидатов. Модели без промежуточных состояний показывают итог. Плавная смена кадра не заменяет отсутствующую историю решателя. Визуальная плавность в живом браузере этой среды не проверена; DOM-проверки подтверждают действия интерфейса и графические данные.

## Разработка и проверки

Python-проверки в подготовленном окружении:

```bash
.venv/bin/python -m pip install -r requirements-dev.txt
.venv/bin/python -m pytest -q tests
```

В Windows используйте `.venv\Scripts\python.exe`. Для DOM-проверок нужен Node.js 22.22.2–22.x, 24.15.0–24.x или 26+ (требование jsdom из lock-файла):

```bash
npm ci
node --test tests/frontend.mjs tests/frontend-v2.mjs tests/preprocessing-ui.mjs tests/validation-ui.mjs tests/accessibility.mjs tests/sources-ui.mjs tests/ux-routes.mjs
```

Проверено: 399 Python-тестов и 52 DOM-теста; после уточнения состава ZIP повторно прошли 28 проверок экспорта.
