# Как пользоваться CML-lab

Проект проходит семь шагов: **Data → Analysis → Pipeline → Estimator → Tuning → Training → Serialization**. Можно возвращаться к любому шагу. Настройки проекта, декларация Pipeline и обученная модель — отдельные объекты: изменение формы не переобучает сохраненный артефакт.

## Первый проект

1. **Data.** Откройте «Датасеты», загрузите таблицу или создайте учебный пример. Нажмите «Использовать» либо **Use in project** в карточке библиотеки. Выберите задачу, цель, признаки и служебные роли. Время, идентификатор объекта и группы запросов должны иметь правильные роли.
2. **Analysis.** Изучите размеры таблицы, пропуски, дубли и основные распределения. Дополнительные графики появляются по кнопке: выберите вид и столбцы, затем создайте график. Вкладка не обучает модель и не меняет данные.
3. **Pipeline.** Выберите **Legacy steps** для последовательности форм либо **sklearn Pipeline** для Python и графического конструктора. Настройте заполнение пропусков, преобразования, кодирование и отбор признаков. В Python-редакторе нажмите **Применить Python**, чтобы проверить декларацию и обновить диаграмму.
4. **Estimator.** Выберите семейство и класс модели. Названия совпадают с API библиотеки: например, `RandomForestClassifier`, `n_estimators`, `max_depth`. Начните со значений по умолчанию; сложные настройки и компоненты открываются отдельными формами.
5. **Tuning.** Выберите метрики и разбиение. Для первого запуска можно отключить автоматический поиск. Затем задайте одну основную метрику и небольшую сетку или диапазоны. Проверяйте бюджет обучений перед запуском.
6. **Training.** Нажмите **Запустить расчет**. Вкладка показывает состояние запуска, затем метрики train и validation, прогнозы и доступные исследования. Итоговый test открывайте после выбора Pipeline и модели. **Сохранить эксперимент** сохраняет результат с его настройками.
7. **Serialization.** **Download .py** и **Download .ipynb** экспортируют текущую конфигурацию проекта с исходными данными. **Download .joblib** скачивает уже обученную модель с подготовкой. **Сохранить проект** сохраняет настройки для повторного запуска.

Запуск и устранение ошибок: [run-platforms.md](run-platforms.md). Экспортируемые проекты запускаются в окружении исходников CML-lab; одного установленного sklearn для всех задач недостаточно. Команды для Windows, macOS и Linux: [project-export.md](project-export.md).

## Задача и роли столбцов

| Задача | Цель и обязательные роли |
|---|---|
| Regression | Числовая цель |
| Classification | Категория или метка класса |
| Clustering | Цель не используется; известная группа может служить отдельной оценкой |
| Ranking | Целая релевантность и идентификатор запроса |
| Forecasting | Числовая цель, время, лаги и горизонт |
| Panel | Числовая цель, время и идентификатор объекта |
| Anomaly detection | Модель учится без метки; известная метка нужна только для оценки |
| Dimensionality reduction | Входные признаки; цель не нужна |

Случайное разбиение подходит независимым наблюдениям. Для будущих значений используйте хронологический порядок и `TimeSeriesSplit`; для новых объектов — групповые разрезы; для ранжирования разделяются целые запросы. Групповой столбец проверки задается явно. Подготовка и модель обучаются заново внутри каждой train-части CV. Validation и test проходят уже обученные преобразования.

Clustering, anomaly detection и dimensionality reduction анализируют весь выбранный рабочий датасет. Автоматический подбор для этих задач отключен: нужен отдельный критерий оценки. Метрики рабочего набора не являются проверкой качества на новых объектах. У трансдуктивных алгоритмов, например `DBSCAN` и `TSNE`, нет сохраненного `predict` или `transform` для новой таблицы; ее нужно анализировать новым запуском.

## Анализ данных

В **Analysis** есть 20 видов графиков в разделах **Distribution**, **Relations**, **Missing data**, **Categorical**, **Groups**, **Time** и **Quality**. ECDF показывает накопленную долю значений, Correlation matrix — связи пар признаков, IQR outlier flags — пометки за межквартильными границами. Пометка не удаляет строку и не доказывает ошибку измерения.

Столбцы и настройки выбираются для каждого дополнительного графика. Для Scatter выберите две числовые координаты; для Time series plot — время и значение; для графика групп — группу и числовое значение. Матрицы позволяют выбрать несколько столбцов. Под графиком указаны использованные строки, выборка и численные сведения. Частоты могут считаться по всем строкам, даже когда отображаемые точки ограничены.

Одновременно остаются до 12 дополнительных графиков. Их удаление и очистка не меняют датасет. Методики, ограничения выборки и все виды графиков: [analysis.md](analysis.md).

## Python и графический Pipeline

В режиме **sklearn Pipeline** исходник объявляет `pipeline = ...`. `Pipeline` передает выход шага следующему; `ColumnTransformer` направляет выбранные столбцы в ветви; `FeatureUnion` передает весь вход каждой ветви и соединяет выходы. Эти композиции можно вкладывать друг в друга. Модель выбирается отдельно на шаге **Estimator**.

После **Применить Python** справа появляется **Feature flow**. Нажмите узел, чтобы изменить класс, имя шага, параметры и selector столбцов. Формы и исходник описывают одну структуру. Перетаскивание узлов и кнопки **↑ / ↓** меняют порядок внутри одного контейнера; для переноса в другую ветвь измените Python. Диаграмма показывает маршруты признаков; число выходных столбцов определяется после обучения.

Мини-IDE подсвечивает синтаксис и предлагает имена классов и параметров. `Tab` вставляет дополнение либо четыре пробела, `Ctrl+Space` открывает подсказки, стрелки выбирают вариант, `Enter` его вставляет. `Escape`, затем `Tab` выводит фокус из редактора. `Ctrl+Enter` внутри редактора применяет декларацию и не запускает обучение.

**Copy Python** копирует исходник; если Clipboard API недоступен, текст выделяется для обычного копирования. **Export .py** сохраняет текущий текст, включая непримененные изменения. **Export .json** сохраняет проверенную декларацию в нашем формате `cml.pipeline`, version `1`. **Import .py / .json** загружает и проверяет файл. **Сохранить Pipeline** сохраняет проверенную подготовку в библиотеку. ПКМ на узле → **Source** либо кнопка **Source** открывает исходник класса из установленной библиотеки sklearn.

Внутри приложения Python декларативный: доступны конструкторы из каталога, литералы, вложенные объекты и разрешенные ссылки. Функции, циклы, lambda, произвольные imports и вызовы `fit` не выполняются. `TargetEncoder`, `RFECV` и `SequentialFeatureSelector` имеют внутреннюю CV и не используются здесь для ordered, time и group задач. Контракты, примеры и бюджеты: [pipelines.md](pipelines.md), [pipeline-editor.md](pipeline-editor.md).

## Поиск гиперпараметров и метрики

**Search breadth** предлагает **Tiny**, **Small**, **Medium**, **Large**, **Wide**. Перемещение ползунка или **Создать готовую сетку** заменяет строки поиска стартовой сеткой выбранной модели. Она остается редактируемой. Варианты проверены по конструктору; они не гарантируют лучшую настройку и могут быть слишком дорогими для выбранных данных. Если содержательной готовой сетки нет, добавьте параметры вручную.

В каждой строке **Parameter** выберите гиперпараметр, затем **Distribution**:

| Distribution | Настройки и применение |
|---|---|
| Choices / Grid | `values`, например `[0.1, 1, 10]`; GridSearch, RandomizedSearch или Optuna |
| Integer range | Целые `low < high`; RandomizedSearch или Optuna |
| Float range | Численные `low < high`; RandomizedSearch или Optuna |

`log` выбирает разные порядки величины и требует положительного `low`. Логарифмический Integer range поддержан Optuna; для RandomizedSearch используйте перечисленные варианты. GridSearch требует точные списки. JSON сохраняет числа, строки, `true`, `false`, `null` и вложенные массивы; Optuna categorical принимает только простые значения. Совместимость зависит от класса и сочетания параметров.

Есть **GridSearch**, **RandomizedSearch**, **Optuna TPESampler**, **Optuna RandomSampler**, **Successive Halving / Grid** и **Successive Halving / Random**. Successive Halving с отбором строк не применяется к time и query/group разрезам. Бюджет ограничен 100 пробами, 500 CV-обучениями и 12 параметрами. Счетчик **Candidates / Trials / CV fits** помогает оценить стоимость; фактические ограничения проверяет сервер.

Для проверенной декларации в **Parameter** доступны вложенные настройки с префиксом `pipeline__`. Например, у корневого `ColumnTransformer` с ветвью `numeric`, содержащей шаг `scale`, параметр называется `pipeline__numeric__scale__with_mean`. Пути берутся из настоящего `get_params(deep=True)` текущего Pipeline. Search breadth заполняет параметры модели; настройки Pipeline добавляются вручную. Каждый кандидат и fold обучает свежую подготовку на своих train-строках.

Выберите одну **Главную метрику** для поиска и нужные метрики результата. Названия, например RMSE, MAE, Accuracy, Balanced accuracy, F1 и F-beta, сопровождаются `?`. Для F-beta задайте `beta`: больше 1 повышает роль Recall, меньше 1 — Precision. `average` определяет объединение оценок классов. Для ranking параметр `k` задает глубину списка. Диагностические величины не всегда имеют направление «лучше» и не все могут быть целью поиска. История показывает реальные кандидаты и их оценки; test не участвует в выборе.

Дополнительные исследования включаются в **Tuning**: путь регуляризации обучает разные модели, кривая обучения сравнивает размеры train, permutation importance перемешивает признаки validation без нового fit. Для неподдерживаемой модели или разреза показывается причина. Это отдельные исследования модели.

## Библиотека, редакции и экспорт

«Моя библиотека» содержит карточки **Проектов**, **Шаблонов моделей**, **Pipelines**, **Datasets** и **Обученных моделей**. Шаблон хранит класс и параметры; обученная модель хранит найденное состояние и подготовку. Карточки моделей показывают доступные validation-метрики и скачивание Joblib. Для других форматов учитывается реальная совместимость; неподдерживаемый формат сопровождается причиной.

Карточка **Dataset** показывает число строк и столбцов, пропуски, типы и размер. **Download .csv** скачивает исходные данные, **Use in project** выбирает редакцию. Изменение таблицы или описания создает новую редакцию с новым идентификатором; прошлые запуски продолжают ссылаться на старые данные. Удаление связанной редакции может быть отклонено с объяснением, пока на нее ссылается сохраненная запись.

Карточка **Pipeline** показывает схему преобразований и экспорт `.py` или `.json` в формате CML-lab. Для проекта доступны `.py` и `.ipynb`. Чтобы отредактировать настройки сохраненного объекта, нажмите **Применить в конструкторе**, измените формы и сохраните. Обновление только названия сохраняет конфигурацию; замена ее настройками конструктора включается отдельным флажком. **Сохранить копию** начинает с параметров выбранного объекта.

Экспорт проекта содержит данные и конфигурацию для повторного Tuning и Training. Для скачивания уже обученных весов используйте экспорт модели. Экспортированный `result.json` скрывает test до явного открытия. Форматы артефактов, снимки и редакции: [project-export.md](project-export.md), [model-artifacts.md](model-artifacts.md), [library-workflow.md](library-workflow.md).

## Учебник и удобство работы

Знак `?` показывает русское пояснение при наведении и фокусе клавиатуры. Нажатие открывает соответствующую статью в новой вкладке. У модели и каждого фактического гиперпараметра есть объяснение, пример, допустимые варианты, ошибки применения и первичный источник. В этой сборке каталог содержит 2911 уроков; состав зависит от установленных библиотек. Английские названия API сохранены, объяснения написаны по-русски. Устройство каталога: [hyperparameter-learning.md](hyperparameter-learning.md).

Ширина настроек меняется ползунком **Ширина настроек** от 360 до 760 px и сохраняется. На узком экране панели располагаются друг под другом. Кнопка в шапке переключает светлую и темную темы. Стрелки, `Home` и `End` переключают вкладки с клавиатуры.

За пределами Python-редактора `Ctrl+Enter` запускает расчет, `Ctrl+S` открывает сохранение проекта; на macOS поддерживается `Command`. Черновик хранится в браузере и восстанавливается кнопкой **Восстановить черновик**. Он не заменяет сохраненный проект, Pipeline или обученную модель.
