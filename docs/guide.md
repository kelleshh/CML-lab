# Как пользоваться CML-lab

## От таблицы до результата

1. Откройте «Датасеты». Загрузите таблицу, выберите источник или создайте пример для нужной задачи. Посмотрите число строк, признаки, пропуски и источник.
2. Нажмите «Использовать». На шаге «Данные и задача» проверьте задачу, цель и признаки. Служебные роли не должны становиться признаками.
3. Выберите оси и цвет исходного графика. Для регрессии удобно показать признак по горизонтали, цель по вертикали; два признака и цель можно посмотреть в 3D. Для классификации используйте классы как цвет.
4. На шаге «Подготовка» добавьте преобразования. Укажите колонки. Предпросмотр показывает реально подготовленные обучающие данные и новые имена признаков.
5. На шаге «Модель» выберите семейство и алгоритм. Начните с параметров по умолчанию. В составной модели компоненты выбираются отдельными формами.
6. На шаге «Проверка» выберите метрики, разделение и CV. Для поиска укажите одну основную метрику и варианты параметров. Нажмите «Запустить расчет».
7. Дождитесь завершения. Сравните обучение и выбор настроек, исследуйте графики. Итоговый тест открывайте после выбора модели и настроек.
8. Сохраните проект для повторного расчета; сохраните эксперимент для неизменного результата. Экспортируйте полный конвейер, если нужно использовать модель вне приложения.

## Что выбрать в поле задачи

| Задача | Цель и обязательные роли |
|---|---|
| Регрессия | Числовая цель |
| Классификация | Категория или метка класса |
| Кластеризация | Цель не используется; известная группа может служить отдельной оценкой |
| Ранжирование | Целая релевантность и идентификатор запроса |
| Временной ряд | Числовая цель, время, лаги и горизонт |
| Панель | Числовая цель, время и идентификатор объекта |
| Аномалии | Модель учится без метки; известная метка нужна только для оценки |
| Снижение размерности | Входные признаки; цель не нужна |

## Пояснения и настройки

`?` показывает пояснение при наведении и фокусе клавиатуры. Нажатие открывает связанный материал в новой вкладке. В учебнике есть примеры, упражнения и источники. Если источник на английском, основное объяснение уже дано по-русски.

Ширина колонки настроек меняется ползунком в верхней части конструктора и сохраняется. На узком экране панели располагаются друг под другом. Светлая и темная темы переключаются кнопкой в шапке.

`Ctrl+Enter` запускает расчет. `Ctrl+S` открывает сохранение проекта. Черновик текущих настроек хранится в браузере; он не заменяет сохраненный проект или обученную модель.

## Дополнительные графики

Срез модели меняет один или два выбранных числовых признака. Другие признаки закрепляются на медианах или наиболее частых значениях обучающей части. У многомерной модели точки могут лежать вне поверхности среза. Для классификации фон показывает предсказанный класс, а точки — известные классы.

Дополнительные исследования включаются на шаге проверки:

- Путь регуляризации обучает отдельную модель для каждого значения α. Это разные задачи оптимизации.
- Кривая обучения обучает полный конвейер на нескольких размерах train и проверяет на одной validation.
- Перестановочная важность перемешивает один исходный признак в validation и измеряет ухудшение выбранной метрики без нового обучения модели.

Эти исследования не используют итоговую тестовую часть. Для временных и групповых данных они требуют другого протокола; приложение показывает ограничение. Записанные промежуточные шаги появляются только у адаптеров, которые действительно их возвращают.

## Сохранение и изменение

«Моя библиотека» содержит проекты, рецепты моделей, препроцессоры, обученные модели и эксперименты. Рецепт хранит выбранный адаптер и параметры. Обученная модель содержит найденное состояние и подготовку данных.

Изменение названия рецепта сохраняет его конфигурацию. Для замены конфигурации настройками текущего конструктора есть отдельный переключатель. Копия сохраняет параметры выбранного рецепта. Если другая форма уже изменила объект, обновите его перед сохранением.

Редактирование таблицы или ее описания создает новую редакцию с новым идентификатором. Старый расчет продолжает использовать прежнюю таблицу. Датасет или модель, на которые ссылается сохраненный опыт, нельзя удалить до удаления соответствующей записи опыта.

Экспорт выбирается в результатах. Паспорт JSON описывает модель; Joblib/Pickle/Skops/совместимый ONNX и ZIP содержат исполняемый артефакт. Формат может быть отключен с причиной. Для Python-экспорта используйте совместимые зависимости. В ZIP есть скрипт прогноза и исходники.

Запуск и устранение ошибок: [run-platforms.md](run-platforms.md). Каталог алгоритмов: [algorithm-catalogue.md](algorithm-catalogue.md). Подготовка данных: [preparation-catalogue.md](preparation-catalogue.md).
