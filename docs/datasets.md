# Данные: источники, библиотека и просмотр

Откройте раздел **Датасеты** в верхнем меню. Здесь хранятся таблицы из файлов, scikit-learn, OpenML и генераторов. Карточка показывает число строк и столбцов, количество пропусков, источник, задачу и выбранную цель. Поиск учитывает название, описание и метки. Фильтры задачи и источника работают вместе.

Откройте карточку набора, чтобы посмотреть исходные значения. Кнопка **Использовать для обучения** переносит выбранную таблицу в конструктор на шаг **Данные и задача**. На этом этапе данные ещё не проходили подготовку и модель ещё не обучалась. В 2D выберите признак по горизонтали и цель по вертикали. В 3D выберите два признака и числовую цель по высоте. Цветом можно показать числовое значение или категорию. Названия признаков и цели выделяются разными цветами, рядом показана их роль. У категорий есть собственные цвета и легенда; номер цвета не становится числовой целью регрессии.

## Задача и формат данных

Задача описывает, что требуется получить от данных. Формат описывает, в каком виде данные представлены. Например, `digits` — задача классификации и формат изображений; для просмотра изображения представлены таблицей числовых пикселей.

| Метка задачи | Что она означает | Что доступно в этой лаборатории |
|---|---|---|
| Регрессия | Предсказать число | Подготовка, обучение и оценка моделей регрессии |
| Классификация | Предсказать класс | Категориальная цель, подготовка, классификаторы, вероятности совместимых моделей и метрики |
| Кластеризация | Найти группы наблюдений | Подготовка, обучение без цели, найденные группы и метрики качества групп |
| Ранжирование | Упорядочить объекты внутри запроса | Столбец запроса, целая оценка полезности, групповое разделение и ranking-модели |
| Временные ряды | Предсказать будущие значения | Столбец времени, лаги и окна из прошлого, последовательные разбиения и прогноз |
| Панельные ряды | Прогноз нескольких объектов во времени | Столбцы времени и объекта, отдельная история каждого объекта и прогноз |
| Поиск аномалий | Найти необычные наблюдения | Обучение без цели; известную метку аномалии можно сохранить отдельно для проверки |
| Снижение размерности | Получить компактное представление | Обучение преобразования, новые координаты и визуализация |
| Другая задача | Назначение не выбрано или не входит в эти категории | Просмотр доступного табличного набора и ручной выбор задачи |

CML-lab работает с восемью задачами из таблицы. Выбранная задача определяет допустимые модели, метрики и разбиения. Числа `0`, `1`, `2`, обозначающие сорта растений, являются классами; выбор числовой регрессии для них требует отдельного предметного обоснования.

У встроенных наборов классификации метки сохранены в столбце `class_label`. Он доступен для осей и окраски графика, но исключён из автоматического выбора признаков и из целей регрессии. Для отдельного учебного опыта можно выбрать реальное числовое измерение целью: например, предсказывать длину лепестка по другим измерениям. Такой опыт решает уже другую задачу.

Задачу, цель, название, описание и метки можно изменить в разделе **Название, задача и метки набора**. Изменение создаёт отдельный снимок таблицы. Исходный набор остаётся в библиотеке. Метка задачи в библиотеке не заменяет настройку опыта: выберите время, объект панели или запрос ранжирования в ролях столбцов. Временной адаптер разбирает и сортирует даты внутри объекта; повторные даты и нерегулярная сетка отклоняются. При разделении метки из train не пересекают границу следующей части.

## Что загружается из scikit-learn

Каталог строится по установленной версии scikit-learn. Он перечисляет публичные функции `load_*`, `fetch_*` и `make_*`. Вариант **Показать весь каталог** включает источники, для которых ещё нет табличного адаптера. У таких карточек есть причина ограничения, а кнопка загрузки заблокирована.

| Встроенный набор | Строк | Исходных признаков | Исходная задача | Поведение цели |
|---|---:|---:|---|---|
| Iris / Ирисы | 150 | 4 | Классификация | Класс не выбирается целью регрессии |
| Wine / Вино | 178 | 13 | Классификация | Класс не выбирается целью регрессии |
| Breast cancer / Диагностика опухолей | 569 | 30 | Классификация | Диагноз сохраняется как класс |
| Digits / Рукописные цифры | 1797 | 64 | Классификация | Пиксели — числа; номер цифры — класс |
| Diabetes / Диабет | 442 | 10 | Регрессия | Числовая цель выбирается автоматически |
| Linnerud / Физические упражнения | 20 | 3 | Регрессия с несколькими целями | Для обучения выбирается одна из `Weight`, `Waist`, `Pulse` |

Эти шесть наборов поставляются вместе с scikit-learn и открываются без загрузки из интернета. В лаборатории `diabetes` по умолчанию загружается с `scaled=False`, чтобы просматривать исходные масштабы. Масштабирование для обучения задаётся отдельно и обучается только на обучающей части данных.

Табличные генераторы поддерживают регрессию, классификацию и примеры групп: `make_regression`, семейство `make_friedman*`, `make_sparse_uncorrelated`, `make_classification`, `make_blobs`, `make_circles`, `make_moons`, `make_gaussian_quantiles`, `make_low_rank_matrix`. Круги, полумесяцы и облака также находятся фильтром кластеризации. Генераторы матриц и многообразий не объявляются классификацией только потому, что их имена начинаются с `make_`.

California Housing, Covtype, KDD Cup 1999 и OpenML требуют сети при первой загрузке. Большие Covtype, KDD Cup и OpenML по умолчанию сохраняют случайную выборку до 10 000 строк. Выборка воспроизводится по зерну; карточка сохраняет исходное число строк и предупреждение. `sample_limit` управляет количеством сохраняемых строк, но загрузчик scikit-learn сначала получает исходный набор: эта настройка не гарантирует ограничение объёма скачивания или памяти при загрузке.

Текстовые корпуса, большие разреженные матрицы, фотографии лиц, пространственные сетки и файлы SVMlight требуют отдельных адаптеров. Их присутствие в каталоге не означает, что они уже доступны для обучения. `digits` является исключением среди изображений: его небольшие изображения имеют готовое табличное представление.

## Своя таблица

Раздел **Добавить из источника → Своя таблица** принимает CSV, TSV и Excel. В первой строке должны быть непустые уникальные названия столбцов. CSV поддерживает разделители запятую, точку с запятой, табуляцию и вертикальную черту; текст читается как UTF-8, а при необходимости — Windows-1251. Числовые строки с десятичной запятой распознаются, если весь непустой столбец допускает такое преобразование.

Импорт автоматически определяет тип столбца. Если все его непустые строки похожи на числа, они становятся числами: `001` превращается в `1`, а текстовые категории `"01"` и `"1"` могут слиться в одну. Кавычки CSV не запрещают определение числового типа. Если столбец содержит и числа, и текст (например, `"01"`, `"1"`, `"a"`), строки сохраняются. Переключателя сохранения исходного строкового типа в импорте пока нет. Чтобы сохранить смысл числоподобных идентификаторов/классов, подготовьте значения с текстовым префиксом, например `id_001` или `class_01`, до загрузки.

При импорте числовые столбцы `y`, `target` и `цель` предлагаются как цель регрессии. Остальные таблицы требуют ручного выбора. Название столбца не доказывает назначение данных: если `y` содержит числовые коды классов, укажите классификацию самостоятельно и используйте столбец для окраски точек. Из одного CSV невозможно надёжно установить смысл чисел.

Поддержан XLSX. Для старого XLS нужен дополнительный движок pandas; если он не установлен, интерфейс предлагает XLSX или CSV. Импорт читает первый лист книги. Формулы Excel должны иметь сохранённые рассчитанные значения: сервис не запускает Excel для пересчёта. Пропуски сохраняются. При обычном обучении с учителем строки без известной цели исключаются с предупреждением; временные задачи проверяют полноту истории отдельно. CML-lab принимает полностью текстовые или категориальные таблицы. Для обучения выберите категориальную цель классификации, кодирование категорий или текстовый векторизатор. В таком наборе числовая цель регрессии автоматически не появляется.

Экспорт набора в CSV сохраняет значения, категории и пропуски сохраненного снимка после определения типов при импорте. Он не экспортирует матрицу после подготовки признаков. Снимок можно удалить, если он не используется запуском или сохранённым экспериментом; связанные снимки не удаляются автоматически.

### Метаданные пользовательской таблицы

При создании набора через API `metadata.roles` содержит объект вида `{"query_column":"query_id"}`. Значения ролей ссылаются на существующие столбцы. `excluded_features` и `excluded_targets` содержат списки неповторяющихся существующих имен; `warnings` — список строк; `params` — объект настроек источника; `source`, `generator` и `description` — строки. `task_target` содержит имя существующей цели или `null`. Некорректная структура возвращает HTTP 422 до сохранения нового снимка.

Изменение метаданных существующего набора поддерживает название, описание, метки, задачу и цель. Служебные роли, сохраненные при создании, сохраняются в дочерних снимках. Роли конкретного обучения выбираются в настройках опыта.

## OpenML

Укажите числовой **ID набора** или название. ID однозначно указывает набор. При загрузке через API по названию можно дополнительно передать точную версию; значение `active` выбирает активную версию и может мешать точному воспроизведению опыта. Параметр `target_column` позволяет указать одну или несколько целей; `null` загружает столбцы без объявленной цели.

Пример запроса к локальному API:

```json
{
  "kind": "openml",
  "params": {
    "name": "iris",
    "version": 1,
    "sample_limit": 10000,
    "seed": 42
  }
}
```

Адаптер определяет исходную задачу по типу цели, которую вернул scikit-learn: категориальная цель даёт классификацию, числовая — регрессию, отсутствие цели — другую задачу. Это техническая подсказка. Числовые коды категорий и смысл временного порядка требуют ручной проверки.

В метаданных `openml` сохраняются доступные ID, название, версия, URL, поле `licence`, авторы и ссылка для цитирования. Значения приходят из описания набора; лаборатория не назначает всем наборам одну лицензию. После загрузки источник отображается как OpenML и находится соответствующим фильтром библиотеки.

Проверки проекта используют небольшой ответ OpenML вместо сетевого обращения, чтобы проверить выбор ID, версии, категории цели и сохранение метаданных. Они не подтверждают доступность любого удалённого набора. Если загрузка завершается ошибкой сети или формата, можно импортировать подготовленный CSV.

## Размеры и точность просмотра

| Ограничение | Значение |
|---|---:|
| Размер загружаемого файла | 25 МБ |
| Сохраняемых строк | 100 000 |
| Столбцов | 1000 |
| Всего ячеек | 5 млн |
| Выходных признаков плотной подготовки | До 2000 |
| Выходных признаков разреженной подготовки | До 20 000 |
| Точек на графике исходных данных | До 2000 |
| Столбцов в матрице корреляции | До 50 |

График использует воспроизводимую выборку строк и сохраняет их исходные индексы. Пропуски координат остаются пропусками; соответствующая точка может не отображаться. Профили столбцов, распределения и корреляция вычисляются по всему сохранённому набору. Корреляция Пирсона описывает линейную связь числовых столбцов; каждая пара использует строки, где оба значения известны. Это не оценка причинности и не проверка нелинейной зависимости.
