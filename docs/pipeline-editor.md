# Pipeline editor

Редактор задает преобразования признаков перед обучением модели. Python и графический конструктор используют одно дерево `sklearn`-объектов. Класс модели, поиск гиперпараметров и обучение задаются в следующих шагах проекта.

## Python и графический конструктор

Введите декларацию `pipeline = ...` и нажмите **Применить Python** или `Ctrl+Enter`. Сервер разбирает импорт, конструкторы и значения параметров, возвращает канонический Python и дерево. Только после успешной проверки диаграмма и формы показывают новую конфигурацию. Неподдерживаемый Python остается в редакторе вместе с сообщением об ошибке.

Пример с отдельными числовыми и категориальными ветвями:

```python
from sklearn.pipeline import Pipeline
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.preprocessing import StandardScaler, OneHotEncoder

pipeline = Pipeline([
    ("features", ColumnTransformer([
        ("numeric", Pipeline([
            ("impute", SimpleImputer(strategy="median")),
            ("scale", StandardScaler()),
        ]), ["age", "income"]),
        ("categorical", OneHotEncoder(handle_unknown="ignore"), ["city"]),
    ], remainder="drop")),
])
```

`ColumnTransformer` направляет исходные столбцы в выбранные ветви. `FeatureUnion` подает весь вход каждой ветви и соединяет выходы. Вложенный `Pipeline` задает последовательность внутри ветви. Одни столбцы можно направить в несколько ветвей.

Новый вложенный контейнер содержит шаг `identity` с `FunctionTransformer()`: он передает вход без изменения. Замените этот шаг своим преобразователем или добавьте следующие шаги. Пустой `Pipeline` библиотека `sklearn` не принимает.

Нажмите узел диаграммы. Справа появятся класс, имя шага, параметры конструктора и selector столбцов. Изменение формы отправляется на ту же серверную проверку и обновляет Python. Параметр **Default** убирает явно заданное значение: используется значение по умолчанию установленной версии `sklearn`.

У `ColumnTransformer` поле `columns` принимает JSON:

| Значение | Что выбирается |
|---|---|
| `["age", "income"]` | Столбцы по именам |
| `[0, 2]` | Столбцы по индексам |
| `[true, false, true]` | Столбцы по булевой маске |
| `{"$slice": [0, 3, null]}` | Столбцы с индексами 0, 1, 2 |
| `{"$call": "make_column_selector", "params": {"dtype_include": "number"}}` | Числовые столбцы |

В полях сложных параметров также используется JSON. `null` соответствует Python `None`, `true` соответствует `True`, `false` соответствует `False`. Python-код разрешенных вложенных конструкторов удобнее редактировать в исходнике.

Шаги одного контейнера можно перетаскивать в списке или на диаграмме: перенесите узел на другой узел с тем же родительским контейнером. Кнопки **↑** и **↓** выполняют то же действие с клавиатуры. Для переноса в другую ветвь используйте Python: перемещение между разными родительскими контейнерами через перетаскивание не реализовано.

## Подсказки и исходники

`Tab` дополняет имя класса или параметра возле курсора; без подходящего имени вставляет четыре пробела. `Ctrl+Space` открывает список дополнений. `↑` и `↓` выбирают дополнение, `Enter` вставляет его, `Escape` закрывает список. Чтобы выйти из редактора клавишей `Tab`, сначала нажмите `Escape`. Подсветка синтаксиса работает без отправки исходника.

**Copy Python** копирует текущий текст. Если браузер запрещает Clipboard API, текст выделяется для `Ctrl+C`. **Export .py** и **Export .json** сохраняют текущий текст, включая незавершенные изменения. JSON использует формат CML-lab:

```json
{
  "format": "cml.pipeline",
  "version": 1,
  "source": "from sklearn.pipeline import Pipeline\n..."
}
```

**Import .py / .json** загружает файл и выполняет серверную проверку. **Сохранить Pipeline** передает проверенную конфигурацию в библиотеку; кнопка недоступна при непримененных изменениях.

Экспорт черновика сохраняет текст для продолжения работы. Он не означает, что Pipeline прошел проверку или готов к обучению.

ПКМ на узле или кнопка **Source** показывает исходник класса из установленной библиотеки `sklearn`, полученный сервером. Для клавиатуры доступна клавиша `ContextMenu` или `Shift+F10`. Исходник библиотеки отображается для чтения; редактируется декларация проекта.

Знак `?` дает русское объяснение. Нажатие открывает материал о конкретном классе, а у параметра добавляет ссылку на его раздел.

## Контракт встраивания

```javascript
const editor = renderPipelineEditor(container, {
  api,
  source: savedPipeline?.source,
  columns: selectedColumns,
  onChange(result) {
    project.preprocessing.declarative_pipeline = result.spec;
  },
  onSave(result) {
    savePipelineRecipe(result.spec);
  },
});
await editor.ready;
```

`api.request()` используется для `GET /cml/pipelines/catalogue`, `POST /cml/pipelines/validate` и `GET /cml/pipelines/source?class=...`. `validate` получает `{source}` либо `{tree}` и возвращает `{source, tree, spec, warnings}`. Префикс `/api` добавляет `ApiClient`. `onDraftChange(source)` вызывается при изменении текста до проверки; `onChange(result)` вызывается после успешной проверки, когда `isValid()` уже возвращает `true`.

Контроллер предоставляет `getSource()`, `getSpec()`, `getTree()`, `isValid()`, `setSource()`, `setSpec()`, `setTree()`, `setColumns()`, `focus()` и `destroy()`. `isValid()` проверяет, что текущий текст применен и запрос проверки завершен. Ошибочный Python не заменяет последнее проверенное дерево.

`PreparationBuilder.values()` отклоняет непримененный или ошибочный Python. `draftValues()` сохраняет текущий текст без попытки обучить старую проверенную конфигурацию. Смена датасета, задачи или режима редактора сохраняет черновик. В проекте доступны `Legacy steps` и `sklearn Pipeline`; активен только выбранный режим.

Диаграмма показывает порядок и маршруты признаков. Количество выходных столбцов она не угадывает: оно определяется после `fit` на train. Статистики преобразований изучаются внутри обучения, а не в редакторе.

Вложенный transformer в `ColumnTransformer.remainder` обозначается одним узлом с именем класса. Его внутренние шаги редактируются в поле `remainder` или Python; диаграмма их не разворачивает. В обычных ветвях вложенные `Pipeline`, `ColumnTransformer` и `FeatureUnion` разворачиваются.

Основа клавиатурной навигации: [W3C WAI-ARIA Combobox Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/combobox/). Для перетаскивания предоставлены кнопки с тем же действием.
