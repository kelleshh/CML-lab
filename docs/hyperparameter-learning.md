# Названия API, параметры и русский справочник

В формах используется точное имя класса: `RandomForestRegressor`, `SVC`, `LGBMClassifier`. Имена гиперпараметров сохраняются как в Python API: `n_estimators`, `max_depth`, `C`, `gamma`. Русский текст объясняет их значение, а не заменяет имя новым термином.

## Найти и изменить параметр

1. Выбери задачу, семейство и класс модели.
2. Начни с раздела основных параметров. Дополнительные поля находятся в раскрываемом разделе. Все поля класса доступны в той же форме.
3. В поиске введи имя параметра или слово из русского объяснения. Поиск раскрывает подходящие дополнительные поля. Скрытые поля сохраняют свои значения и входят в конфигурацию запуска.
4. Наведи курсор на `?` или перейди к нему клавишей Tab: откроется краткое русское объяснение. Нажми `?`, чтобы открыть отдельную статью в новой вкладке.
5. Сравни исходное и измененное значение по одинаковой проверке. Смотри метрику, время, предупреждения и размер обученного артефакта.

Статья показывает смысл, пример, исходное значение формы, значение установленного класса по умолчанию и ограничения формы. Эти два начальных значения могут различаться: лаборатория может использовать ограниченный вычислительный бюджет. `None` имеет смысл конкретного API: автоматический выбор, отсутствие ограничения или отключение операции. Не заменяй `None` на `0` без чтения статьи.

Поля массивов, словарей, вложенных estimators и kernels принимают декларативный JSON согласно схеме. Изменение JSON не исполняет произвольный Python. Ошибку сочетания параметров установленный исполнитель может обнаружить при построении или обучении; наличие отдельного поля не означает совместимости с каждым значением остальных полей. Например, `penalty`, `solver` и `dual` зависят друг от друга, а native categorical режим требует соответствующего входа.

## Одинаковое имя может иметь разный смысл

| Поле и класс | Что означает |
|---|---|
| `Ridge.alpha` | Множитель L2-штрафа линейных коэффициентов |
| `MultinomialNB.alpha` | Псевдосчета для сглаживания вероятностей событий |
| `GaussianProcessRegressor.alpha` | Добавка на диагональ ковариации, описывающая шум или стабилизацию |
| `GradientBoostingRegressor.alpha`, `LGBMRegressor.alpha` | Уровень quantile или поддерживающий параметр Huber objective |
| `SelectFdr.alpha` | Уровень статистического отбора по выбранной FDR-процедуре |
| `SVC.gamma` | Локальность RBF-сходства |
| `XGBClassifier.gamma` | Минимальный выигрыш нового split |
| `AdaptiveLassoRegressor.gamma` | Степень адаптивного штрафного веса |
| `HuberRegressor.epsilon` | Порог остатка после деления на обученный масштаб |
| `SVR.epsilon` | Полоса ошибок без штрафа в единицах цели |
| `MLPClassifier.epsilon` | Численная добавка в знаменателе Adam |
| `DBSCAN.eps` | Радиус соседства |
| `GaussianRandomProjection.eps` | Допуск искажения расстояний для автоматического бюджета проекции |
| `Lars.eps` | Численная стабилизация матричной факторизации |
| `MCPRegression.weights` | Веса штрафов отдельных подготовленных признаков |
| `VotingRegressor.weights` | Веса ответов моделей ансамбля |
| `KNNImputer.weights` | Вклад соседних train-строк в заполнение |
| `QuantileTransformer.subsample` | Максимальное число train-строк оценки квантилей, не доля |

Для `MCPRegression.weights` длина массива совпадает с числом выходов Pipeline. Это не число исходных строк. One-hot, полиномиальные признаки и отбор могут изменить нужную длину.

## Учебник Pipeline

Статья `cml-declarative-pipeline` объясняет последовательные шаги, параллельные ветви и направление признаков. Каждому классу конструктора соответствует собственный материал, каждому constructor-параметру — отдельная статья. Параметр в статье класса имеет якорь `#param-key`: Mini-IDE может открыть сразу нужный фрагмент.

`Pipeline` передает выход предыдущего шага следующему. `ColumnTransformer` направляет выбранные столбцы в отдельные ветви. `FeatureUnion` направляет весь вход каждой ветви и соединяет результаты; выбор столбцов сам по себе он не выполняет. Все три конструкции могут быть вложены.

`fit` учит статистики только по train текущего разреза. `transform` применяет их к validation и test. До запуска проверь имена входов, число и порядок выходов, sparse/dense и сохранение пропусков в preview. Допустимые декларации, классы и ограничения описаны в [pipelines.md](pipelines.md).

## Метрики и анализ

`fbeta-metrics` объясняет `beta`, `binary`, `macro`, `weighted` и `micro`. `beta>1` усиливает значение recall, `beta<1` — precision. Параметр меняет оценку прогнозов, а не обучающий loss и не threshold автоматически.

`dataset-analysis` объясняет histogram, box, violin, ECDF, QQ, scatter, hexbin, correlation, KDE, missing patterns, сравнение групп и временной ряд. IQR flags отмечает строки, сохраняя исходные данные. Error bars среднего группы показывают стандартное отклонение значений, не доверительный интервал. Для графика всегда проверяй число использованных строк и предупреждения о подвыборке.
