# Каталог алгоритмов CML-lab

`cml_lab.infrastructure.ml.catalogue.AlgorithmCatalogue` хранит определения алгоритмов и создает библиотечные модели. Он не обучает модели, не хранит пользовательские рецепты и не управляет выполнением.

```python
catalogue = AlgorithmCatalogue()
algorithms = catalogue.list("classification")
definition = catalogue.spec("random_forest_classifier")
estimator = catalogue.build(
    "classification", "random_forest_classifier",
    {"n_estimators": 100, "max_depth": 6}, seed=42, n_jobs=2,
)
```

`descriptor` является синонимом `spec`; `catalogue()` возвращает полный список, `list_task(task)` возвращает алгоритмы одной задачи. Все методы чтения возвращают независимые копии метаданных.

Каталог содержит 117 определений: 51 регрессор, 32 классификатора, 13 методов кластеризации, 3 ранжирующих модели, 5 методов поиска аномалий и 13 методов уменьшения размерности. Временным и панельным адаптерам доступны 50 регрессоров; обычный стекинг исключен. Сам вызов `build("forecasting", ...)` создает регрессор: сортировку времени, лаги и проверку будущего выполняет соответствующий runner.

29 прежних идентификаторов линейных моделей сохранены. Они создаются через публичные методы совместимого `linear_lab.models.ModelRegistry`. Новый каталог не вызывает его приватные методы.

Дополнения XGBoost, LightGBM и CatBoost загружаются при обращении к их определениям, а не при создании каталога. Ошибка импорта или загрузки нативной библиотеки отключает соответствующие определения с причиной. Остальные модели остаются доступны. Проверенная среда: sklearn 1.8.0, xgboost-cpu 3.4.1, LightGBM 4.7.0, CatBoost 1.2.10.

Для каждого поля задаются тип, допустимые значения или диапазон, пример смысла, уникальный `help_key` и `lesson_id`. Значения `select` сохраняют тип варианта: расстояние `p=2` является целым числом, а не строкой `"2"`. Неизвестные параметры, бесконечные числа и булевы значения вместо числового параметра отклоняются. Реестр не исполняет пользовательский код и не импортирует присланные пользователем имена классов.

Голосование и стекинг поддерживают готовые наборы и поле `components` с вложенными моделями. Компонент имеет вид `{algorithm_id, params}`. Не больше восьми компонентов на одном уровне и трех уровней вложенности; хотя бы две модели; один вид задачи. Для мягкого голосования каждому компоненту необходима реальная `predict_proba`. Стекинг использует библиотечные out-of-fold ответы, а не ответы моделей на их собственное обучение.

Возможности sparse input и пропусков для новых sklearn-моделей получаются из публичного `sklearn.utils.get_tags`. Возможности прогнозирования, преобразования и вероятностей отражают библиотечные методы. LOF, DBSCAN, агломеративная и спектральная кластеризация не получают искусственный прогноз новых строк. t-SNE и SpectralEmbedding возвращают карту обученного набора, но не обещают `transform` новой строки. Возможность модели может зависеть от выбранного параметра: например, SGD с `loss="hinge"` не дает вероятностей, а hard voting не имеет `predict_proba`. Runner проверяет фактическую модель перед вычислением такой метрики.

Для методов с дорогой матрицей попарных расстояний или ковариации определение содержит `capabilities.max_rows`. Runner проверяет предел до обучения. Для Poisson задана неотрицательная цель; для Gamma строго положительная. Ограничение Tweedie зависит от выбранного `power`.

CatBoostClassifier возвращает классы массивом `(n, 1)`, большинство sklearn-классификаторов массивом `(n,)`. Runner приводит одиночную цель к одномерному списку. Вероятности XGBoost имеют точность float32; нельзя требовать от них точность нормировки float64.

Проверки `tests/test_cml_catalogue.py` создают и клонируют все доступные модели, действительно обучают классификаторы на трех классах, регрессоры на числовой цели, кластеризаторы без цели, методы аномалий и уменьшения размерности. Все три нативных ранжирующих библиотеки обучены с правильным контрактом запросов: XGBoost `qid`, LightGBM размеры `group`, CatBoost `group_id`. Отдельно проверяются небезопасные значения, глубина ансамбля и отсутствие OpenMP у одной библиотеки без остановки всего каталога.
