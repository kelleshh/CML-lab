# Моя библиотека

Библиотека разделяет настройки до обучения и обученные артефакты. Название объекта помогает найти его; `id` определяет объект, а `revision` определяет редакцию настроек.

## Models

Карточка обученной модели содержит `task`, `algorithm` и доступные `Validation metrics`. На карточке показаны первые четыре числовые метрики; после выбора модели доступен полный список с вопросами и ссылками на учебник. Скрытые test-метрики в карточке не появляются.

**Download .joblib** скачивает полный обученный артефакт: подготовку признаков и модель. В подробностях раздел **Другие форматы модели** запрашивает реальные возможности экспортера. Недоступная кнопка показывает причину; библиотека не считает ONNX доступным для любого алгоритма.

**Открыть результат** возвращает сохраненный результат запуска. Изменение названия или описания не переобучает модель. Удаление модели, используемой сохраненным экспериментом, сервер отклоняет: сначала удалите связанный эксперимент.

Шаблон модели хранит алгоритм и параметры до обучения. Он находится в отдельной категории и не содержит обученных коэффициентов или весов.

## Datasets

Карточки показывают количество строк, столбцов, пропусков, задачу и источник. **Download .csv** экспортирует исходные строки. **Use in project** передает выбранный набор в проект. **Edit rows** открывает редактор таблицы.

Выберите карточку, чтобы изменить `name`, `description`, `tags`, `task` и `task_target`. **Сохранить новую версию** создает новый `dataset_id` с `parent_id`, указывающим на исходный набор. Строки и описание старого набора сохраняются. Завершенные запуски продолжают использовать свои снимки.

Поиск применяется по `Enter` или кнопке **Search**. Фильтр `task` и поиск работают совместно. Пагинация содержит по 24 карточки; количество найденных наборов показывается рядом со стрелками.

Удаление требует подтверждения и касается выбранного `dataset_id`. Сервер отклоняет удаление набора, используемого запуском или сохраненным экспериментом. При таком отказе карточка остается на месте, а сообщение сервера объясняет причину.

## Pipelines

Карточка декларативного Pipeline содержит диаграмму, построенную из дерева после серверной проверки Python. `Pipeline` показывает порядок, `ColumnTransformer` показывает выбранные признаки ветвей, `FeatureUnion` показывает параллельные ветви и объединение выходов. Диаграмма в библиотеке предназначена для просмотра; редактирование выполняется в [Pipeline editor](pipeline-editor.md).

**Download .py** экспортирует Python. **Download .json** экспортирует собственный формат CML-lab. Для декларативного Pipeline это `{format: "cml.pipeline", version: 1, source: "..."}`. Старые рецепты подготовки показывают последовательность этапов; для них сервер экспортирует собственный формат подготовки и исполняемый адаптер CML-lab. Старые этапы не выдаются за декларативное дерево `sklearn`.

Если сервер не принимает сохраненный исходник, карточка показывает причину вместо придуманной схемы. Python остается в сохраненном рецепте и доступен для исправления.

## Projects и редактирование настроек

Карточки проекта экспортируют `.py` и `.ipynb` через серверный экспортер. Конфигурация проекта включает данные, преобразования признаков, модель, разбиение, подбор параметров и обучение.

Название и описание рецепта можно обновить, сохранив его параметры. Для замены параметров включите **Заменить параметры текущими настройками конструктора**. **Сохранить копию** копирует выбранный объект, даже если открытый конструктор содержит другую конфигурацию. Сохранение использует `expected_revision`, чтобы конфликтующее обновление не перезаписало чужую редакцию.

Библиотека вызывает серверные API; локальные карточки не являются отдельным хранилищем данных.

## Проверка интерфейса

```sh
node --test tests/cml-pipeline-editor.mjs tests/cml-library.mjs
```

Для тестов нужен `jsdom` из dev-зависимостей и Python окружение проекта. При отличающемся пути задайте `CML_LAB_PYTHON`. Тесты библиотеки создают отдельное временное хранилище, запускают настоящий FastAPI и обучают малую Ridge-модель в worker. Они проверяют CSV, `.joblib`, Pipeline `.py`/JSON, Project `.py`/`.ipynb`, создание нового снимка dataset и сохранение параметров при переименовании и копировании. Отрисовка выполняется в jsdom: пиксельный вид браузера этими проверками не подтверждается.
