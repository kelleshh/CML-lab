# Сохранение и экспорт обученных моделей

Алгоритм из каталога, пользовательский рецепт и обученная модель являются разными объектами. Завершенный запуск сохраняет полный `FittedArtifact`: обученный препроцессор, estimator, исходные признаки, кодирование классов и временной контракт при наличии.

Application-сервис `ArtifactApplication` получает `RunRepository` и `ArtifactGateway`. Он разрешает экспорт и прогноз только завершенному запуску. Паспорт, CSV и ZIP получают исключительно `Run.public_dict()`; они используют ту же политику закрытого теста, что и интерфейс. У сервиса нет импортов sklearn, pandas, joblib или FastAPI.

Файловый адаптер `LocalArtifactGateway(root, catalogue, data_gateway)` читает только `root/artifacts/<32-hex-run-id>.joblib`. Внешние загрузки моделей не принимаются. Symlink-файлы, переходы за каталог и артефакты больше 256 МБ отклоняются.

| Формат | Что сохраняется | Ограничения |
|---|---|---|
| Joblib | Полный обученный Python-артефакт | Собственный доверенный файл; нужны совместимые версии зависимостей |
| Pickle | Тот же артефакт, protocol 5 | Те же ограничения доверия и окружения |
| Skops | Поддерживаемый полный артефакт | Неизвестные типы перечисляются в паспорте; перед загрузкой их проверяют вручную |
| ONNX | Полный совместимый конвейер от исходных столбцов до ответа | Конвертация и реальная проверка через ONNX Runtime обязательны; при отказе указана причина |
| ZIP | Joblib, паспорт, требования, исходники и inference.py; доступные Skops/ONNX | Исходные CSV датасета в архив не входят |
| JSON/паспорт | Схема входа, версии, запрос и открытые результаты | Закрытые тестовые строки и метрики отсутствуют до открытия теста |
| CSV | Доступные строки прогнозов с названием части данных | Тест исключен до открытия; файл содержит UTF-8 BOM для табличных редакторов |

ONNX поддерживает новую стандартную подготовку, заполнение числовых пропусков, стандартные скейлеры, подписанные log1p/sqrt, обрезку по обученным границам, совместимые one-hot/полиномиальные этапы и библиотечные модели с конвертером. Классификационный граф декодирует итоговый класс: пользователь получает исходное название, а не внутренний номер. Вероятности сравниваются с Python-моделью.

Числовой вход ONNX имеет тип float32, пропуск передается как NaN. Этап конечности заменяет бесконечности на пропуск так же, как Python-конвейер. Строковые категории передаются строковыми тензорами без null. Если проверочные исходные категории имеют пропуск, такой экспорт отключается; Python-форматы сохраняют полное поведение заполнения.

Дата, текст, frequency/target encoding, совместимый старый составной препроцессор и часть структурных/внешних estimator пока не имеют нового проверенного ONNX-конвертера. Для них доступны собственные Python-форматы. Экспорт коэффициентов без препроцессора не подменяет полный конвейер.

Для ряда или панели обычный `predict` требует временной протокол. Используйте `ArtifactApplication.forecast(run_id, history, future)`: сохраненные лаги строятся из известной истории. При горизонте 1 прогноз предыдущего будущего шага становится частью истории для следующего. Готовый PCA переносит новые строки через `transform`; t-SNE, DBSCAN и другие трансдуктивные алгоритмы объясняют, почему готового переноса нет.

После распаковки ZIP:

```bash
python -m pip install -r requirements.txt
python inference.py --input rows.csv --output predictions.csv
python inference.py --history history.csv --future future.csv --output forecast.csv
```

Первую команду запускают в отдельном окружении с версией Python из паспорта. В Windows, macOS и Linux необходимы совместимые библиотечные колеса; для LightGBM на macOS может понадобиться OpenMP. Экспорт не является самостоятельным исполняемым файлом.

Возможности форматов проверяются фактически. Кеш хранит до четырех подготовленных экспортов и максимум 50 МБ. Если Skops или ONNX не подходит, capability содержит объяснение; ошибка одной библиотеки не отключает Joblib/Pickle.

Проверки `tests/test_cml_artifacts.py`: точные исходные Python-прогнозы после повторной загрузки, русские классы, ONNX-прогнозы/вероятности и пропуски, неизвестная категория, отказ неподдержанной даты, изолированный новый Python-процесс ZIP, закрытый/открытый тест, ручное доверие Skops, ограничения пути и рекурсивный временной прогноз с заранее известным ответом.

Источники: [sklearn 1.8: сохранение моделей](https://scikit-learn.org/1.8/model_persistence.html), [Skops: доверенные типы](https://skops.readthedocs.io/en/stable/persistence.html), [sklearn-onnx: исходный DataFrame](https://onnx.ai/sklearn-onnx/auto_tutorial/plot_gbegin_dataframe.html).
