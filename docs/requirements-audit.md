# Проверка требований CML-lab

Отчет относится к текущему исходному проекту CML-lab. Численные возможности определяются зарегистрированными адаптерами, а не наличием кнопки в интерфейсе.

| Требование | Реализация | Проверка и граница |

| DDD и Clean Architecture | Пять контекстов, доменные состояния, прикладные сценарии и порты; внешние библиотеки в infrastructure/presentation | Изолированный импорт и AST-проверки зависимостей; ревизии, отмена, неизменные результаты; координация запуска и удаления; один сервер на папку данных |
| Другое оформление и удобные настройки | Кремовый/графит/бордовый; семь этапов проекта; колонка настроек 360–760 px; клавиатура и контекстная помощь | Настоящие компоненты DOM; сохранение ширины; визуальные пиксели и WebGL требуют браузера |
| Classic ML вместо только линейных моделей | 117 уникальных адаптеров, восемь задач; деревья, леса, бустинг, ансамбли, соседи, SVM, Байес, линейные/устойчивые модели и разложения | Настоящие библиотечные вычисления; каталог задает поддерживаемые задачи, формы и доступность |

## Существенные ограничения

- Pipeline принимает декларативный Python с зарегистрированными классами и функциями. Произвольные callbacks, metadata routing, пользовательские imports и циклы не исполняются.
- Каталог обширный, но не включает каждую существующую ML-библиотеку и каждый исследовательский метод.
- Ряды и панели используют библиотечные регрессоры с лагами и окнами. Это не полный каталог ARIMA/ETS и не эконометрические fixed/random effects.
- Обычный sklearn-стекинг запрещен для временных, групповых и упорядоченных данных: его внутреннее разделение не соблюдает их протокол.
- Путь штрафа, кривая размера обучения и перестановочная важность доступны для подходящих регрессий/классификаций с независимыми строками. Неподдерживаемая настройка возвращает причину.
- SMOTENC/SMOTEN отключены, поскольку конвейер не сохраняет требуемую структуру категорий для этих методов. SMOTER/SMOGN применяются к числовой регрессии.
- Каталог sklearn содержит также неподдерживаемые источники. Сетевая доступность OpenML и крупных загрузчиков не подтверждается локальными тестовыми ответами.
- ONNX доступен только для конвейера, который успешно конвертируется и проходит проверку прогнозов. Joblib/ZIP сохраняют полный Python-артефакт.
- Общая защита удаления и запуска относится к операциям приложения. Ручное удаление файлов и отказ файловой системы не покрываются общей транзакцией SQL/FS.
- Нужен Python 3.12; первый запуск устанавливает зависимости. Автономного бинарного приложения в архиве нет.

Команды и фактические результаты проверок находятся в [verification.md](verification.md).
