# Учебник и помощь в CML-lab

Учебник открывается по `/lesson`. Рядом с полем формы знак `?` показывает краткое объяснение; ссылка открывает соответствующую статью в отдельной вкладке. В статье есть конкретный пример, действие настройки, способ проверить эффект, ошибки применения и ссылки на источники. Кнопка «Открыть учебный пример» переносит рецепт в форму лаборатории. Обучение запускается пользователем.

Начни со статьи `task-map`: она связывает смысл строки, нужный ответ, доступные признаки и будущий сценарий проверки.

Каталог поддерживает поиск и фильтр по задаче. Формулы показаны рядом с числовым примером. Источники на английском отмечены явно; основной текст написан по-русски. «Печать / PDF» использует обычный диалог браузера и оставляет материал без навигации.

## Маршруты изучения

| Задача | Начало | Следующие материалы |
|---|---|---|
| Регрессия | `01-prediction`, `03-least-squares` | Регуляризация, устойчивые модели, деревья, леса, бустинг, соседи |
| Классификация | `classification-basics` | Матрица ошибок, метрики, вероятности, порог, калибровка, семейства моделей |
| Кластеризация | `clustering-basics` | Плотность, иерархия, смеси, внутренние и эталонные метрики |
| Ранжирование | `ranking-groups` | Релевантность, запросы, NDCG/MAP/MRR, групповые разрезы |
| Временные ряды | `forecasting-lags` | Горизонт, доступное прошлое, последовательная проверка, MASE |
| Панель | `panel-groups` | Истории отдельных объектов, временная проверка и перенос на новые объекты |
| Аномалии | `anomaly-detection` | Оценка необычности, порог, отдельный режим новых объектов |
| Уменьшение размерности | `dimensionality-reduction` | Компоненты, объясненная дисперсия, разреженный вход, ограничения рисунка |

Подготовка разбита на статьи о пропусках, масштабировании, категориях, тексте, датах, новых признаках, отборе, уменьшении размерности и пересэмплировании. `dataset-sources` объясняет роли таблицы; `experiment-versions` разделяет рецепт, запуск и обученный артефакт.

## Проверяемые объяснения

Уроки используют официальную документацию установленной версии scikit-learn 1.8, imbalanced-learn, XGBoost, LightGBM, CatBoost, pandas; открытые учебники ISLP и Forecasting: Principles and Practice; материалы авторов linearmodels и Яндекса. Дополнительные статьи и энциклопедии в сохраненных линейных уроках помечаются дополнительным чтением. Ссылки поясняют факты; большие фрагменты источников не копируются.

Слова с разным смыслом объясняются в конкретной форме. У Huber `epsilon` относится к остатку, деленному на обученный масштаб; у SVR — к полосе в единицах цели. У SVM `gamma` меняет локальность RBF; у SCAD/MCP — форму штрафа. Сила штрафа `alpha` не имеет общей числовой нормировки для всех алгоритмов. Меньший `C` означает более сильное ограничение соответствующей модели.

Уроки по времени указывают, какие факты известны к моменту прогноза. Лаги панели разделяются по объекту. Target encoding не разрешается для строгих временных и групповых сценариев без соответствующего адаптера. Метрики ранжирования считают списки отдельных запросов. В CML-lab NDCG использует экспоненциальную полезность `2^relevance−1`; при релевантностях 3,0,1 пример дает около 0.983. MAP/MRR считают положительную релевантность полезной, k по умолчанию равно 10. Статья описывает веса запросов, совпавшие оценки и пустую релевантность. У кластеризации эталонная метка не входит в обучение. Внутренние метрики исключают шум -1, ARI/AMI оценивают все строки с -1 как меткой. Доля отмеченных аномалий — диагностика без направления улучшения; она не заменяет эталонную оценку качества.

Публичная история обучения зависит от алгоритма. Модель, предоставляющая только `fit`, не получает вымышленные итерации потери. Рисунок и плавная анимация не заменяют фактическую обучающую историю.

## Контракт учебного контекста

`contexts/learning/domain.py` содержит неизменяемые `Lesson`, `LessonSection`, `HelpEntry`, `SourceReference`. `ports.py` описывает чтение репозитория. `application.py` обеспечивает поиск и получение материалов. Эти файлы используют стандартную библиотеку и не импортируют вычислительные библиотеки, HTTP или хранилище.

`infrastructure/learning.py` собирает каталог из 32 сохраненных линейных уроков и 36 материалов CML. Composition root передает ему обычные словари алгоритмов, этапов подготовки, sampler и метрик. Каждое фактическое поле получает отдельную подсказку по своему `help_key`, материал по `lesson_id`, ограничения формы и числовой пример. Учебный контекст не читает реестр sklearn самостоятельно.

| API | Результат |
|---|---|
| `GET /api/learning/lessons` | Краткие записи `{items,total}`; параметры `query`, `task`, `family`, `level` |
| `GET /api/learning/lessons/{id}` | Полный материал, источники и учебный рецепт |
| `GET /api/learning/help/{key}` | Краткое и подробное объяснение, пример, эффекты, ограничения и статья |
| `/lesson?id={id}` | Самостоятельная страница конкретного материала |
| `/?lesson={id}` | Заполнение формы лаборатории учебным рецептом |

Неизвестная ссылка дает ошибку отсутствующего материала. Возвращаемые записи независимы от каталога: изменение полученного словаря не переписывает исходный урок. Обновление рецепта в лаборатории сохраняет отдельную ревизию, а завершенный запуск хранит свой эффективный снимок.

## Проверки и границы

`tests/test_learning_context.py` проверяет сохранение старых ссылок, соответствие статей задачам, все учебные конфигурации через настоящие фабрики алгоритмов, ссылки каждой формы, различные смыслы перегруженных параметров и числовые примеры метрик. `tests/learning-page.mjs` проверяет клиентскую навигацию, фильтр, отдельную вкладку источников, отсутствие подмены неизвестного материала, текстовое отображение внешних данных и перенос рецепта без автоматического обучения.

Эти проверки не подтверждают доступность каждого внешнего сайта в будущий момент и визуальный вид страницы на реальном устройстве. Дополнительный алгоритм с отсутствующей библиотекой остается недоступным с причиной; открытие его учебной формы само по себе не устанавливает библиотеку.


## Как выбрать подготовку

Выбирай преобразование по конкретной проблеме таблицы. Сравни исходный вариант и один измененный рецепт на одной проверке.

| Что видно в таблице | Что проверить | Материал |
|---|---|---|
| Пропущенные измерения | Медиана, индикатор пропуска; затем соседнее или итеративное заполнение | `22-missing-values`, `iterative-imputation` |
| Разные единицы: возраст около 20, доход около 100000 | Масштабирование перед расстояниями, линейным штрафом и PCA | `05-scaling-correlation` |
| Города, типы товаров | One-hot без выдуманного порядка; политика новой категории | `categorical-encoding` |
| Длинный числовой хвост | Преобразование и смысл реальных крайних значений; обрезание меняет данные | `24-feature-engineering` |
| Связь изгибается по одному измерению | Локальные сплайны или полином; проверь выход за диапазон | `spline-features` |
| Много столбцов | Отбор по обучению; при MI явно проверь дискретность входов | `feature-selection` |
| Датчик или магазин измеряется снова | Роль объекта, время, прошлые лаги, соответствующее разбиение | `panel-groups`, `forecasting-lags` |
| Редкий класс | Сначала матрица ошибок, затем веса или resampling только внутри обучения | `classification-metrics`, `classification-resampling` |

Сплайн с пятью узлами и степенью 3 дает шесть столбцов на один вход в текущем адаптере. Итеративное заполнение обучает модели пропусков, а не основную модель задачи. Если обучающий столбец был полным, новый пропуск в нем заполняется медианой при действующем `skip_complete=true`. Материалы и подсказки объясняют этот случай отдельно.

## Численные примеры для самопроверки

| Настоящий ответ и прогноз | Что должно получиться |
|---|---|
| Ответы 1,0; вероятности положительного класса 0.8,0.3 | Brier=0.065; log loss≈0.290 |
| Ответы 1,0,1,0, уже расположенные по убыванию оценок | ROC AUC=0.75; average precision≈0.833 |
| Релевантности 3,0,1 в полученном порядке | NDCG@3≈0.983 при полезности `2^relevance−1` |
| Известны дни 1,2,3 со значениями 10,20,30; origin=день 4 | lag1=30, lag3=10, среднее окна 3=20; horizon=3 относится к дню 6 |

Проверки сравнивают эти примеры с вычислительным адаптером и независимо рассчитанными ожиданиями. Проверка старта приложения также проходит через новый каталог подготовки, чтобы ссылка на отсутствующий урок не блокировала сервер.
