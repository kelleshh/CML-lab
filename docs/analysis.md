# Анализ исходного датасета

Раздел анализа работает внутри проекта до подготовки, поиска параметров и обучения. Он читает выбранную редакцию датасета и не изменяет строки. Обзор показывает размеры таблицы, пропуски, число дублей и три основных графика: пропуски по столбцам, распределение первого числового столбца и частоты первого категориального столбца, если такие столбцы есть.

Дополнительные графики строятся по кнопке. Выберите раздел, английское название графика и столбцы. Можно исследовать разные сочетания признаков без одновременной генерации всех пар. Вопросительный знак объясняет настройку на русском; щелчок открывает урок `dataset-analysis` в новой вкладке.

| Раздел | Графики |
|---|---|
| Distribution | Histogram, Box plot, Violin plot, ECDF, Normal Q-Q plot, Kernel density estimate |
| Relations | Scatter plot, 3D scatter plot, 2D histogram, Correlation matrix |
| Missing data | Missing values by column, Missingness matrix |
| Categorical | Category counts, Category cross-tabulation |
| Groups | Box plot by group, Group mean |
| Time | Time series plot, Rolling mean, Autocorrelation |
| Quality | IQR outlier flags |

Одновременно остаются до 12 дополнительных графиков. Добавление следующего убирает самый старый дополнительный график. Основной обзор сохраняется. Кнопка удаления графика и очистка графиков не удаляют датасет.

## Область вычисления

Каждый график подписывает число использованных строк, общий размер набора и наличие ограничения отображаемых точек. Численные сведения и правила выборки доступны под графиком.

Частоты Histogram, 2D histogram, Category counts, Missing values и Group mean вычисляются по всем подходящим строкам. ECDF использует все непустые значения, учитывает повторы и может проредить только точки отображаемой линии. Correlation matrix использует непустые пары отдельно для каждой пары столбцов; число строк каждой пары возвращается в `pair_counts`.

Scatter, 3D scatter, Box plot, Violin plot, Q-Q и KDE ограничивают размер отображаемой выборки через `sample_size`. Выборка воспроизводится с тем же `seed`. Для IQR-порогов используются все непустые значения, а точки могут быть ограничены. Missingness matrix показывает не более 1000 строк. `sample_size` допускает от 1 до 5000 строк; число столбцов матрицы ограничено 20.

Категории ограничены `top_k` от 2 до 20. Category counts объединяет оставшиеся категории в отдельный столбец. Cross-tabulation и графики групп явно сообщают число исключенных редких строк. Пропуски описываются отдельно и не превращаются в реальную категорию.

## Как читать результаты

- ECDF в точке x показывает долю непустых значений, которые не больше x. Для `[1, 1, 2, 4]` высота в точке 1 равна 0.5.
- Normal Q-Q plot сравнивает данные с нормальными квантилями. Он не является автоматическим доказательством нормальности.
- KDE использует `scipy.stats.gaussian_kde` с правилом Scott. Постоянный столбец не дает определенной плотности такого вида.
- Pearson описывает линейную связь, Spearman — монотонную связь рангов. Постоянный столбец дает `null`, а не ложный нулевой коэффициент. Корреляция не устанавливает причину.
- Group mean показывает среднее и стандартное отклонение значений группы. Полоса ошибки не является доверительным интервалом среднего.
- IQR outlier flags помечает значения за границами `Q1 - 1.5 * IQR` и `Q3 + 1.5 * IQR`. Пометка не означает ошибку данных и не удаляет строку.

Time series plot и Rolling mean сначала сортируют строки по времени. Окно Rolling mean измеряется наблюдениями, а не днями. Среднее использует текущую и прошлые строки. Для использования такого среднего как признака прогноза цели нужна отдельная задержка, настроенная в Pipeline.

Autocorrelation требует одну последовательность с уникальными равномерными моментами. Для панели сначала выберите один объект или подготовьте отдельный датасет. Пропущенная дата, смешанные объекты и повтор времени вызывают понятный отказ. Нормировка: сумма произведений центрированных значений при сдвиге, деленная на полную сумму квадратов центрированного ряда. Постоянный ряд не имеет определенной автокорреляции.

Обзор всей исходной таблицы — исследование данных. Он не должен использовать отдельный итоговый test для ручного выбора параметров модели или преобразований по правильным ответам. Правила подготовки обучаются внутри train и частей CV при реальном расчете.

## HTTP API

`GET /api/cml/analysis/kinds` возвращает 20 видов графиков, требования к столбцам, объяснения и пределы.

```json
{
  "dataset_id": "идентификатор редакции",
  "kind": "scatter",
  "columns": ["age", "income"],
  "options": {"sample_size": 1500, "seed": 42}
}
```

Отправьте запрос на `POST /api/cml/analysis`. Ответ содержит `traces` и `layout` для Plotly, `explanation`, `statistics` и `sample_info`. Для `kind: "overview"` ответ дополнительно содержит `summary`, `columns`, `graph_types` и до трех `plots`.

Допустимые параметры: `sample_size`, `seed`, `bins`, `top_k`, `window`, `max_lag`, `corr_method`. Для `corr_method` доступны `pearson` и `spearman`. Анализ ограничен непустой таблицей до пяти миллионов ячеек. Числовые координаты не принимают bool и категории. Запрос не обучает Pipeline и не запускает модель.
