# Проверка лаборатории

Проверки основаны на согласованных требованиях и публичных контрактах из `docs/contracts.md`. Тестовые данные создаются из известных формул; ответы не подбираются под текущую реализацию. Все записи выполняются в временных каталогах pytest. Сетевые загрузки для этих проверок не нужны.

| Сценарий | Что проверяется | Независимое ожидание |
|---|---|---|
| Точное линейное восстановление | Коэффициенты, свободный член и метрики всех трех частей | Формула `y = 5 + 3*x1 - 2*x2` без шума |
| Разделение и масштабирование | Каждая строка входит ровно в одну часть; доли 60/20/20; преобразования не видят проверку и тест | Отдельно обученная цепочка sklearn StandardScaler и Ridge |
| Подбор настроек | Изменение ответов вне обучения не меняет модель, путь регуляризации и перекрестную проверку | Два опыта с одинаковой обучающей частью и разными ответами остальных частей |
| Ridge и Lasso | Ridge сокращает величину коэффициентов; Lasso исключает бесполезные признаки | Данные с одним сильным полезным признаком и пятью независимыми бесполезными |
| SGD | Записываются разные реальные эпохи; ошибка уменьшается; итоговые предсказания близки к известной зависимости | Формула `y = 1 + 2*x1 - x2` |
| Lars и OMP | Предсказания каждого кадра совпадают с его коэффициентами; ошибка кадра пересчитывается напрямую | Прямое умножение исходной матрицы на записанные коэффициенты |
| Huber, RANSAC и Theil–Sen | Восстанавливают исходную зависимость при 10% больших выбросов в ответах | Чистая прямая `y = 1 + 2*x` на новой сетке точек |
| Перестановочная важность | Перемешивание полезного признака ухудшает качество; перемешивание известного бесполезного признака не влияет | Чистая зависимость `y = 3 + 4*x1` при независимом `x2` |
| Ограничения модели | Gamma и Poisson явно отказывают для отрицательной цели | Математическая область допустимых целевых значений |
| Метрики | Недопустимые результаты имеют значение null и причину; постоянная цель не дает выдуманного R² | Области определения метрик и прямой расчет ошибок |
| Tweedie | При power=0 разрешены отрицательные числа; результат совпадает с MSE | Девианс при power=0 равен средней квадратичной ошибке |
| Своя метрика | `mean(abs(error))` считает запрошенную величину; обращения к Python, атрибутам и генераторам отвергаются | Ручной расчет трех абсолютных ошибок и разрешенный числовой язык |
| Настоящий расчет через API | Запускается рабочий процесс, результат сохраняется, выгрузки содержат реальные предсказания | Сквозной опыт с известной прямой |
| Скрытая тестовая часть | До явного открытия нет тестовых метрик и строк в ответах API и выгрузках JSON/CSV | Согласованный режим итоговой проверки |
| Кадры при скрытом тесте | Массив предсказаний каждого кадра выровнен с отображаемыми строками | Точки графиков одного шага должны относиться к тем же наблюдениям |
| Сохранение и перезапуск | Эксперимент, данные и экспортированная модель переживают повторное создание приложения | Файловое состояние в изолированном временном каталоге |
| Отмена | Расчет можно остановить; частичный результат не выдается как обученная модель | Незавершенный расчет не пригоден для экспорта |
| Загрузка своей таблицы | CSV с русскими заголовками и UTF-8 BOM загружается через HTTP, обучается и используется для новых предсказаний | Известная прямая `цель = 2 + 3*расстояние` |

Запуск:

```bash
python -m pytest -q tests/test_training.py tests/test_api.py
```

Эти проверки не подтверждают доступность внешних источников OpenML или sklearn через интернет, визуальную плавность интерфейса и скорость на пользовательских больших таблицах. Эти свойства требуют отдельной проверки в соответствующей среде. Тесты загрузчиков данных находятся в `tests/test_datasets.py`.

Итоговый прогон: **24 проверки прошли за 39,09 с**, из них 19 численных и 5 сквозных проверок API. Тестовый клиент Starlette вывел одно предупреждение о будущем переходе с httpx на httpx2; ошибок выполнения нет.



## Итоговая интеграция

Финальный полный прогон Python: **85 passed**, 105.77 с. Он включает загрузчики данных, обучение, API, произвольные оси сохраненного конвейера и скрытие предсказаний в незавершенном расчете.

`node --test tests/frontend.mjs`: 10 passed. Используются настоящие app.js/charts.js и JSDOM, записанный результат TrainingService; HTTP и отрисовщик Plotly заменены на тестовые реализации. Проверяются каталоги, запросы метрик/разделения, исключение целевой колонки, пресеты, сравнение, сохранение/восстановление, редактор строк и перенос точки с новым обучением. Это не проверка внешнего вида в браузере.

Первый запуск `python run.py --no-browser --port 8877` создал отдельную `.venv`, установил зависимости и выдал здоровый HTTP API с 29 моделями.

Графическая проверка в браузере не выполнена: среда не смогла открыть вкладку для просмотра. Внешний вид и плавность анимаций требуют проверки на компьютере пользователя. Сетевые загрузки OpenML/California не проверены этим прогоном.
