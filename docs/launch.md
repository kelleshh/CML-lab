# Запуск CML-lab

Инструкция для Windows, macOS и Linux, параметры запуска, расположение данных и диагностика находятся в [run-platforms.md](run-platforms.md).

Требуется Python 3.12 или новее. Основной запускатель — `run.py`; Python-приложение создается функцией `cml_lab.presentation.http.api:create_app`.
